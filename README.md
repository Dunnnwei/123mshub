# 123 MSHub（Memory & Skill Hub）

> 123mshub —— 本地 agent 的共享大脑管理器。目录、仓库名、EXE 与路径等简短场合一律写作 `123mshub`。
>
> **免费 · 全开源（MIT）**——没有账号、没有云端、没有订阅，数据全在你自己的文件夹里。

**123 MSHub** 是一个给「人」用的 Windows 桌面工具，为你的本地 agent（ZCode、WorkBuddy、
Claude Desktop、Cursor 等）管理两类共享资产：

| 资产 | 内容 | agent 怎么用 |
|---|---|---|
| **技能库（Skills）** | GitHub 技能 + 本地自研技能 + 程序仓 | 挂载/复制安装，统一更新与安全检查 |
| **记忆库（Memory）** | 索引 + 条目文件（一人一条知识） | 注入提示词教 agent 先读索引、按需读条目、往 inbox 投递 |

核心理念：你在任意本地 agent 里**粘贴一段注入提示词**，agent 即获得
读共享记忆、用共享技能库、投递新记忆的完整协议。程序只做管理与审查，
不管同步——同步、迁移、复制由你自己的工具搞定（网盘、NAS、U 盘都行）。

## 快速开始（三步）

1. **解压即用**：下载 `123mshub-vX.Y.Z-win64.zip`，解压到任意目录，双击 `123mshub.exe`；
2. **首启三件事**：
   - 设定**仓库位置**（本地一个文件夹，建议放进你的同步盘）；
   - **AI 接口**可填可不填（安全审查 B 路线 + 记忆辅助共用；不填程序照用，只是没有 AI 能力）；
   - GitHub Token 可选（匿名也能用，仅限流更严）；
3. **复制注入提示词**：侧栏或记忆库页顶部「复制注入提示词」→ 粘贴给你的 agent 的
   对话首条消息，或放进常驻配置（AGENTS.md / CLAUDE.md / 自定义指令 / 系统提示词）。

### 连通暗号

注入提示词带一个彩蛋：向已接入的 agent 发送 `天王盖地虎`，
它应该只回一行：

```
AI镇河妖！暗号对齐，123mshub已接入，当前仓库拥有X条记忆，X项技能。
```

（X 为复制提示词那一刻仓库的记忆/技能实数。）一眼确认 agent 已接入。
个别模型可能加引号或客套，以关键词「暗号对齐」为通过标准。

## 记忆库：怎么用

- 数据模型：`memory\MEMORY.md`（索引）+ `memory\notes\*.md`（条目，一个文件一条知识，带 frontmatter）
  + `memory\inbox\`（agent 投递区，agent 唯一可写区）；
- **索引 MEMORY.md 是程序维护的派生物**：手动改它会在下次重建时被覆盖——改内容请走条目编辑；
- 六个日常场景：审核 agent 投递（红点 → 预览 → 收编）、手动记一条、搜索查阅、修正过时、
  删除（软删除，进 `.meta\memory-trash\`）、总览分发（统计条 + 复制注入提示词）；
- 跨机：文件夹自己同步，程序启动自动对账（含冲突副本隔离、索引重建）。

### 整理与日报

记忆和技能可以交给两条路整理，都产出到 `memory\reports\`：

- **值守 Agent**：记忆库页「值守 Agent」→ 复制值守整理提示词，交给一个常驻 agent
  （比如 NAS 上的总机）部署。它有值守权限（可直接整理 notes 条目），周期性整理并写日报；
- **手动「归纳整理」**：随时点一下。程序先本地盘点（数字由程序计算），配置了
  「AI 接口」时再调用该 LLM 生成整理分析，合成日报；
- 「整理日报」按钮随时查看历史日报。日报内容仅限记忆与技能的汇报信息。

### 导入记忆技能库

设置页「导入记忆技能库」：从任意目录打捞可识别的记忆与技能（支持 123mshub 仓库互导、
DSH 总机 brain 资产、Engramory 式索引、任意 agent 的散装记忆与 SKILL.md 技能目录），
扫描预览 → 后台导入（含整理去重与日报，进度可见）。只写本仓库、不改来源目录；
重复导入幂等。搬家、换 agent、收编历史资产，一个按钮搞定。

## 常见问题

- **SmartScreen 提示「Windows 已保护你的电脑」**：未签名 EXE 的正常现象，点
  「更多信息 → 仍要运行」即可；发布页提供 SHA256 校验值，可先核对再运行；
- **双击没反应 / 浏览器打开**：桌面窗口依赖 Edge WebView2 Runtime（Win11 自带）；
  缺失时程序自动改用默认浏览器打开，不影响使用；
- **端口占用**：默认端口 8766（与旧 123skillrepo 的 8765 分开，两者可同时开）；
- **杀毒软件短暂锁文件**：所有落盘动作已内置退避重试，一般无感；若报错重试即可。
