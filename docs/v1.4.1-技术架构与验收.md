# v1.4.1 原生功能补全：技术架构与验收

实施分支：`native/v2`。以功能补全提示词、历史清单及 v1.3.3 行为为准。

## 边界与组件

延续 PySide6 Widgets + 本地 Sigma 图谱岛。所有业务调用经过 native facade，复用
MemoryService、SkillRepository、TidyService、ImportService、ConfigStore 与 JobManager。
不启动 HTTP 服务，不改核心数据格式，不迁移仓库和用户配置。

读操作由 TaskRunner 投递，Qt 主线程交付结果；输入变化立即使旧请求失效，300ms
只负责搜索节流。写操作/安装/更新/检查/整理/导入由现有单线程 JobManager 执行。
窗口关闭不取消后台导入；主程序退出前等待运行中的任务。任务完成以变更信号刷新
记忆统计、投递箱、技能列表、安全中心及已创建的图谱，避免陈旧图谱缓存。

## 配置与凭据

配置目录固定为 `%APPDATA%\mshub\`，沿用 v1.x。`--repo` 是 SessionConfigStore 的
内存覆盖。只有 `--repo-and-save` 或用户设置页明确保存仓库才改默认目录。
`--config-dir` 使用独立配置、独立锁、内存凭据，不访问系统钥匙串，用于测试。
正常会话凭据继续由 ConfigStore 访问系统 keyring；设置页只展示脱敏提示，草稿保存
前不生效，清除密钥也必须随保存提交。切换供应商后不默默把旧供应商密钥发给新地址。

WebEngine 只在首次打开图谱时创建，持久化数据和缓存分别落于
`%APPDATA%\mshub\web-profile` 与其 `cache` 子目录。既有其他 Qt 默认目录不自动迁移或删除。
单实例使用文件锁，不监听 TCP；双开提示 4 秒自动关闭。

## 交互与验收口径

保持 123UI v4.2 皇家蓝与亮/暗/System；原生文本通过 QTranslator 翻译，中英文不改
用户资产正文。Markdown 预览用 QTextDocument，禁止加载外部资源；双链由显式按钮导航。
图谱在 file/qrc 页面使用有界主线程 FA2，避免 Chromium 对外部 worker 的限制；非 file 页面
可使用 graphology 的本地 Blob worker，初始化失败时同样降级同步布局，绝不以 HTTP 服务规避 file 限制。

每片核对既有测试和新增原生集成测试，使用隔离仓库、假 keyring 与模拟 AI 响应。
冻结包单独验本地资源、WebChannel、Sigma 节点/刷新和零 TCP 监听。运行前后比较真实
config.json 字节与凭据指纹（只记录一致性，不输出密钥）。并排截图和实测记录补充在本文件。
冷启动记录主窗可交互耗时；主进程驻留内存与打开图谱后的子进程分别记录；发布体积
包含 Chromium，单独记录实际值。

最终人工实测门槛：在真实仓库保存其他供应商配置并成功生成 AI 草稿，完成
「投递→收编→图谱新节点」。自动化模拟通过不能替代这两项真实验收。
