## P0：悬停淡出实际失效（rgba alpha 在 sigma WebGL 中不生效）——必须修

**根因（已核实到 node_modules 源码，不要试图用 rgba 修 rgba）：**
sigma v3 渲染器使用预乘混合 `gl.blendFunc(gl.ONE, gl.ONE_MINUS_SRC_ALPHA)`，但
`floatColor → rgbaToFloat` 不做预乘，节点/边着色器内部输出 `v_color` 也未乘 alpha。
因此 `rgba(166,166,166,0.10)` 实际渲染为**接近不透明的亮灰**，淡出完全反效果。

涉及：`web/src/components/MemoryGraph.vue:124`（节点淡出色）、`:136`（边的焦点/非焦点色）。

**修法（sigma 官方范式）：淡出一律用「向画布底色混合的不透明 hex」伪造：**

1. 新增工具函数：
   ```js
   // ratio = 前景保留比例；bg 为当前主题画布底色
   function blendToBackground(foreground, ratio, bg) { /* round(fg*ratio + bg*(1-ratio)) */ }
   ```
2. 底色**不得写死**：初始化时用 `getComputedStyle(surfaceRef)` 读取
   `.memory-graph-surface` 实际背景色；程序支持亮/暗双主题，主题切换后需重算混色
   （监听主题变化或每次 `load()`/`refreshRenderer` 时惰性重取）。标签 halo 描边色
   （`drawMemoryLabel` 里写死的 `#171717`）与 `labelColor` 的 `#b8b8b8` 同步改为主题相关。
3. 混色保留比例（暗色主题下的参考产出值，亮色主题按底色现算）：

| 用途 | 前景 | ratio | 暗色产出（bg≈#141414） |
|---|---|---|---|
| 淡出节点 | 类型色 / #A6A6A6 | 0.10 | ≈ #232323 |
| 非焦点边 | #8C8C8C | 0.12 | ≈ #222222 |
| 焦点普通边 | #8C8C8C | 0.45 | ≈ #4A4A4A |
| **悬停节点的邻边** | 悬停节点类型色 | 0.60 | 紫系柔光 |

4. Obsidian 细节：悬停时**与悬停节点相连的边改用该节点的类型色**混合显示（发光感的来源），
   不再统一灰色。

## P1：三处交互保真度

1. **停稳后拖拽失去弹簧**（`:238-241` 停表 1.8s 后 FA2 冻结 + `:278-283` 拖拽未重加热）：
   `downNode` 时若 layout 存在则 `layout.start()` 重新加热并清掉停表；`mouseup` 后按原逻辑
   （节点数 >1800 用 2.6s 否则 1.8s）重新挂停表。目标：任何时候拖节点，邻居都被弹簧牵引。
2. **搜索敲一字、全图抖一次**（`:357-360` 筛选 watch 调了 `restartLayout(false)`）：
   query / 类型开关 / 孤儿开关只 `refreshRenderer()`，**不得重启布局**；仅 `includeTags`
   （换数据）与力参数变化可重启。Obsidian 的筛选从不移动节点。
3. **平移时边全部消失**（`:334` `hideEdgesOnMove: true`）：改 `false`；仅当边数 > 8000 时
   动态置回 `true` 兜底。Obsidian 平移缩放时边始终可见。

## P2：力面板两个「安慰剂滑杆」

1. `:231` `edgeWeightInfluence: forces.link` 只作用于**边权重**，而当前边无 weight 属性，
   弹簧滑杆无效。修法：`syncGraph` 建边时写入 `weight`（双链 2、共同标签 0.5）。
2. `:227` 斥力×距离相乘耦合进 `scalingRatio`，两滑杆互相干扰。解耦：
   - 斥力 → `scalingRatio`（单独映射，范围维持 20~220）；
   - 连接距离 → 改为**边权重倍率**（距离越大、弹簧越弱：weight × (2.0 − distance/160×1.5)，
     即 40→×1.6、160→×0.5 一类的反向线性，保持滑杆文案不变）；
3. `adjustSizes` 改 `true` 常开（BarnesHut 已开，防节点叠成色块；3000 节点性能测试把关）。

## P3：小项（顺手修，不扩范围）

1. **搜索不匹配改「变暗」不「隐藏」**（`:122`、`:115`）：query 未命中的节点/边用 P0 的
   淡出色 + `label: null`，不设 `hidden`；类型/孤儿筛选才走 `hidden: true`。
   （Obsidian 行为：保留空间语境。）
2. **邻居集合缓存**（`:111`）：`isNeighbor` 每帧每节点调 `graph.neighbors().includes()`，
   改为 `enterNode` 时算好 `Set` 存模块级变量，`nodeReducer/edgeReducer` 用 `has()`；
   `leaveNode` 清空。
3. **tooltip 边界钳制**（`:250-261`、`:404`）：left/top 超出画布时钳回
   （参考 surface 的 clientWidth/Height 与 tooltip 自身尺寸，留 12px 边距）。
