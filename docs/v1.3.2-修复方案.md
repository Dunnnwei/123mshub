# 123mshub v1.3.2 修复方案

## 目标

针对 v1.3.1 首次打开记忆图示、筛选栏圆角遮挡和记忆类型标签显示问题，完成一个补丁版本，保持现有主题色、iOS 27 glass 浮层和 Obsidian 风格图谱交互。

## 实现方案

1. **Sigma 节点程序注册**
   - 保留 `user`、`project`、`reference`、`feedback` 作为业务类型，以便颜色、筛选和悬停逻辑继续使用。
   - 将四种业务类型全部映射到 Sigma 内置 `NodeCircleProgram`，并显式配置 `nodeProgramClasses`。
   - 不把业务类型改写成通用 `circle`，避免破坏类型筛选、图例和标签显示。

2. **筛选栏圆角层级修复**
   - 圆角、边框和背景只由 `.filter-select` 外层承担。
   - 关闭的原生 `select` 使用透明背景，避免矩形背景覆盖外层右侧圆角。
   - 深色和亮色主题仍分别设置原生下拉选项的颜色、背景和 `color-scheme`，保证展开菜单可读。
   - 保留移动端宽度、焦点态和现有玻璃主题，不通过删除全部圆角降低视觉质量。

3. **中文类型标签**
   - 记忆库的统计筛选和批量分类选项统一显示“用户、项目、参考、反馈”。
   - 内部值仍使用稳定的 `user/project/reference/feedback`，不影响接口和数据兼容。

4. **版本与验收**
   - Python、前端和发布元数据统一升级到 v1.3.2。
   - 运行前端类型检查、单元/性能测试、构建、Python 测试、编译检查和发布验收。
   - 复查新增代码不引入 shell、提权、持久化或运行时下载行为，并确认最终 EXE 可启动。
