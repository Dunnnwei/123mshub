## 〇、先修债务（P0，加功能之前必须完成）

### P0-1 `--repo` 参数静默污染用户配置【实测事故】

- **现状**：`src/mshub/native/app.py` 中 `if args.repo: store.save({"repo_root": args.repo})`。
  任何带 `--repo` 的启动（测试、冒烟、误用）都会把用户真实仓库指针改掉——本次验收期间
  用户配置的 `repo_root` 被改成了临时目录，程序打开变空仓库。
- **修复**：`--repo` 只做会话内覆盖，**不落盘**。需要「打开并记住」的场景（未来文件关联）
  用独立显式参数 `--repo-and-save`。补测试：带 `--repo` 启动后 config.json 逐字节不变。
- **顺带**：此坑已按纪律回写《v1.4.0-迭代历史与避坑清单.md》§C-9，修完在清单勾掉。

### P0-2 设置页补齐全部编辑能力（用户当前最痛）

现状：AI 接口只有只读状态行——用户已有的 DeepSeek 配置**无法查看、修改、清除**；
GitHub Token、镜像、代理、抓取方式全都没有编辑入口。逐项补齐（对照 v1.3.3 设置页）：

| 设置项 | 控件 | 行为规格 |
|---|---|---|
| AI 接口·地址 | QLineEdit + 六供应商预设下拉 | OpenAI / DeepSeek / OpenRouter / SiliconFlow / 智谱 GLM / 阿里云百炼，选中预设自动填 base_url；预设名保持英文（GBK 坑） |
| AI 接口·模型 | QLineEdit（支持自动拉取则下拉） | v1.3.3 语义：自建网关可从 /models 拉取列表，失败回退手填 |
| AI 接口·密钥 | 密码框 + 「测试连通」按钮 | 写入走 keyring（ConfigStore 既有接口）；显示脱敏（头尾各 4 位）；**必须有「清除已存密钥」按钮**（用户现在想换掉 DeepSeek 就靠它）；测试连通调一次轻量请求出中文结果 |
| GitHub Token | 密码框 | 同上脱敏 + 清除；匿名可用仅限流的说明文案 |
| 镜像 | 列表编辑 | v1.3.3 的常用镜像快捷填入按钮沿用 |
| 代理 | QLineEdit + 检测按钮 | 只读代理检测：检测结果只填草稿，保存才生效（v1.3.0 语义） |
| 抓取方式 | QComboBox | archive / git 二选一 |
| 语言 | QComboBox | 中文 / English / System，**真实生效**（Qt 翻译装载，不只是存值） |
| 「重新识别已同步条目」 | 按钮 | 触发现有 reconcile + 记忆对账（self_heal 编排），后台任务 + 结果提示 |
| 「导入记忆技能库」 | 按钮 | 打开导入流程（见 §四） |

保存走 ConfigStore 草稿-保存模型（改了不点保存不生效，与 v1.3.3 一致）。

### P0-3 文档口径修正（两处）

- 配置目录**事实**是 `%APPDATA%\mshub\`（SERVICE_NAME=mshub，v1.x 起如此），
  《v1.4.0-技术架构.md》写的 `%APPDATA%/123mshub/` 是错的——**改文档，绝不改代码迁移目录**
  （零迁移红线）；
- WebEngine profile 实际落在 `%APPDATA%\123mshub\123 MSHub\QtWebEngine\`，与架构文档
  「web-profile」口径不一致——代码归一到文档口径，或改文档记录事实，二选一写明。

### 1.3 详情/编辑抽屉（完整规格）

      created/updated 只读小字（updated 保存时自动刷新，不可手填）；

- [ ] **「放大编辑窗口」**（v1.2.4 功能）：编辑抽屉标题栏放大/还原按钮，
