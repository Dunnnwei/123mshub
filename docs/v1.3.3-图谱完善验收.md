## 交付结论

v1.3.3 已完成附件《v1.3.3-图谱完善方案》中的 P0–P3 图谱目标，并将图谱参数保存从页面生命周期延长到桌面 WebView 配置目录。Sigma 报错 `could not find a suitable program for node type "project"` 已通过把四类业务枚举映射到 Sigma 内置圆形节点程序修复；实际打开图示页时控制台没有 error/warn。

主程序和环境包已分开：主 EXE 内含 Python、FastAPI、前端静态资源、Sigma、Graphology 和 ForceAtlas2，不需要另外安装 Python、Node.js、npm 或 pip；Windows 原生桌面窗口使用的 WebView2 和 .NET Framework 4.8，以及可选的 Git for Windows，放在独立环境包中。首次启动仍需要用户在设置中选择或确认记忆/技能仓库目录。

## 图谱验收

### P0：主题与透明度

- Sigma WebGL 的淡出颜色改为根据 `.memory-graph-surface` 实际背景计算出的不透明十六进制颜色，避免 rgba 在不同 WebGL 层上的 alpha 表现不一致。
- 暗色和亮色主题分别从运行时 CSS 变量读取画布底色、标签色、面板色和边框色；主题切换后重新计算节点/边颜色。
- 非焦点节点约使用 10% 前景色、非焦点边约使用 12% 前景色，焦点边约使用 45%，悬停邻边使用悬停节点类型色；标签绘制带同色画布晕边。

### P1：布局与交互

- 拖动节点时重新加热 ForceAtlas2，松开后在 1.8 秒（大图约 2.6 秒）后停止；筛选、搜索和类型开关只刷新渲染，不重启布局。
- `hideEdgesOnMove` 仅在关系数超过 8000 时开启；本次实测 51 条关系保持可见。
- 记忆图示页实际显示 `58` 个节点、`51` 条关系，刷新、缩放、复位和设置面板均可用。

### P2：边权与节点尺寸

- 双链边默认权重为 `2`，共同标签边默认权重为 `0.5`，并依据连接距离参数进行反向距离倍率调整。
- ForceAtlas2 的斥力使用 `scalingRatio`，连接影响使用 `edgeWeightInfluence`，`adjustSizes` 固定为 `true`，避免节点圆形互相覆盖。

### P3：搜索、悬停与提示框

- 搜索未命中节点和边保留在画布中并使用不透明混色变暗，不会突然改变空间结构；“GitHub”搜索实测能将未命中内容压暗并保留命中内容。
- 悬停邻居使用缓存的 `Set`，避免每次重绘重复计算邻接集合。
- 节点提示框按图谱容器和提示框自身尺寸钳位，并限制最大宽高、长文本换行，避免贴边或被窗口裁切。
- 当前运行页的浏览器控制台日志：error/warn 均为 0。

## 设置持久化验收

图谱设置键为 `mshub.memoryGraph.settings.v1`，保存共同标签边、孤儿节点、四类节点筛选、节点尺寸、标签阈值和四项 ForceAtlas2 参数。

实测步骤与结果：

1. 打开图谱设置，开启“共同标签边”，把“节点尺寸”从 `1` 调到 `1.3`；界面立即显示 `51` 条关系、设置面板显示 `1.3`。
2. 切换到技能库，再回到记忆图示；设置仍为“共同标签边 checked”和“节点尺寸 1.3”。
3. 刷新页面并重新进入图示页，再打开设置；以上两项以及其他默认参数仍被恢复。
4. `src/mshub/gui.py` 使用非私有 WebView 配置目录 `APPDATA\\mshub\\webview`，为桌面重启后的 localStorage 提供稳定落点；本次自动化验收直接覆盖了页面刷新和切页，原生 WebView2 窗口的字体/窗口外观未用自动化截图替代人工观察。
