## 一、记忆图示（用户反馈 ①，三个子项）

### 1-1 暗色主题配色失效

- **现状**：亮暗切换后图谱仍显示亮色系配色。
- **修复要求**：图谱岛配色**必须跟随 Qt 主题**——主题切换信号 → bridge 推送主题
  （架构已定义 `getTheme()`/主题同步）→ 页面按避坑清单 §D-1 纪律重算全部混色
  （向画布底色混合的**不透明 hex**：淡出节点 0.10 / 淡出边 0.12 / 焦点边 0.45 /
  悬停邻边=节点类型色 0.60；标签色与 halo 同步）。注意：岛内不要依赖
  `getComputedStyle` 猜背景——画布底色由 bridge 显式下发，和主题切换即时联动。
- **验收**：亮暗主题各截一张与 v1.3.3 同机对照；切换即时生效不重启。

### 1-2 节点漂浮/律动感（静态动效）

- **目标**：节点有轻微的呼吸漂浮感（参照 Obsidian 图谱的闲置微动）。
- **实现规格**：
  - **只做显示层偏移，不动 FA2 物理位置**：每节点按 id 播种相位，正弦漂移
    幅度约 1~2px、周期 3~6 秒（各节点相位错开，避免整体同步晃动的假感）；
  - 单个 `requestAnimationFrame` 循环驱动 sigma 重绘，不新建对象、不重跑布局；
  - 用户交互（拖拽节点/平移/缩放）期间暂停漂移，交互结束 1~2 秒后恢复；
  - 系统「减少动态效果」开启时（或岛设置里给开关）默认关闭；
  - 大图（>8000 边）自动降频或关闭，保 60fps 优先。
- **验收**：静止时节点有生命感；拖动/缩放无拖泥带水；3000 节点冒烟不掉帧。

### 1-3 力参数设置面板回归（v1.3.3 有、原生丢了）

- **恢复 v1.3.3 的图谱设置面板**（三组，参照 `docs/design/obsidian-graph-settings.png`
  与 v1.3.3 行为）：
  - **Filters**：类型四选、孤儿节点开关、共同标签边开关（开=请求数据带 tag）；
  - **Display**：节点尺寸滑杆、标签阈值滑杆；
  - **Forces**：中心力 / 斥力 / 弹簧 / 连接距离四滑杆——FA2 映射沿用 v1.3.3 语义
    （斥力→scalingRatio、弹簧→edgeWeightInfluence+边权重、连接距离→权重倍率反向、
    adjustSizes 常开），滑杆拖动有可感知布局变化；
  - 面板做在图谱岛页面内（HTML 浮层，同 v1.3.3），持久化走
    `readGraphSettings()/writeGraphSettings()` bridge（架构已定义，落 ConfigStore）。
- **验收**：与 v1.3.3 图谱设置逐项对照；设置重启保留；调整不重置布局。

## 二、记忆库统计行语言统一（用户反馈 ②）

- **现状**：「总数、user、project、reference、feedback、本周新增、待收编」中英混用。
- **修复**：统计行文案词条化进 i18n，**跟随语言切换全中文或全英文**：
  - 中文：总数 / 用户 / 项目 / 参考 / 反馈 / 本周新增 / 待收编；
  - English：Total / User / Project / Reference / Feedback / New this week / Inbox；
- **顺带纪律**：全程序扫一遍同类中英混用（列表徽章、类型下拉、按钮、占位符文案），
  一并词条化——本次至少统计行与类型相关控件必须清零混用。

## 三、编辑窗口化（用户反馈 ③，记忆 + 技能同款）

- **现状**：记忆编辑是页内抽屉，挤压列表空间；技能编辑信息同理。
- **改造**：改为**独立编辑窗口**（QDialog 非模态）：
  - 可拖移、可拖角调节尺寸、默认 `min(1100px, 85%屏宽) × 75%屏高`，
    记住上次几何（位置+尺寸），下次原样打开；
  - 非模态：编辑时列表仍完整可见可用（这正是本次改造目的）；
  - 单窗口复用：已开编辑窗时点另一条目，复用同窗口加载（避免同条目双开冲突）；
  - 保存/软删除/刷新列表走既有信号路径；删除二次确认保留；
  - 记忆编辑窗内功能不减：frontmatter 表单、正文编辑/预览、双链徽章、AI 生成描述、
    重名提示+「打开它」（见 §五-2）；
  - 原「放大编辑」按钮移除（被窗口化取代）；
  - **技能库「编辑信息」同款改独立窗口**（身份与归属分离表单全量保留）。
- **验收**：列表在编辑期间完整显示；窗口尺寸位置重启保留；两种窗口与 v1.3.3
  编辑功能逐项对齐不减配。
