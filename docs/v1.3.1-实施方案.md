# 123mshub v1.3.1 实施方案

## 目标与基线

本次以当前工作区 v1.3.0 和 `记忆图示.md` 为需求基线，版本升级为 v1.3.1。保持皇家蓝、亮暗两套主题和 iOS 27 glass 浮层；图谱画布按 Obsidian Graph View 的暗色视觉校准，但使用项目可合法安装的 `sigma@3.0.3` 回退包（`@sigma/core` 在当前 npm registry 不可用）。

## 实现范围

1. **首屏性能**：将健康检查拆为 SQLite/配置的快速只读状态；仓库恢复、manifest 对账、同步盘自愈、记忆索引重建移到后台一次性任务。列表读取不再每次触发恢复；后台完成后通过状态字段和前端短轮询刷新。首次窗口先呈现可用壳层和加载态，避免等待全量磁盘扫描。
2. **侧栏主操作**：只把“复制注入提示词”按钮本身做成皇家蓝填充，说明文字回到透明侧栏卡，不扩大蓝色背景范围。
3. **亮暗控件**：统一 `select` 原生下拉菜单颜色、字体尺寸和主题 token；修正技能库筛选、批量按钮、记忆库排序与工具按钮的同层级字号。
4. **技能名兜底**：对历史 SQLite/manifest 中缺失名称的技能，根据 GitHub `source_url` 解析为 `owner/repo[/subdir]`，否则使用已有作者/仓库或安全目录名生成稳定名称，并回写数据库、manifest、index，避免列表首项空白。
5. **迁移说明**：迁移实现仍只做 `.manifest.json → _manifest.json` 的同内容原子改名；所有用户界面和 CLI 文案改为通用同步程序描述，不绑定飞牛 NAS。
6. **Sigma 图谱**：
   - 依赖：`sigma@3.0.3`、`graphology`、`graphology-layout-forceatlas2`；布局使用 worker 版，主线程只负责 WebGL、事件和 UI。
   - API `/api/memory/graph?kinds=link` 默认只返回双链；只有打开“共同标签边”才请求 `kinds=link,tag`，避免数千节点的 O(n²) 默认开销。
   - 确定性伪随机初始位置、FA2 gravity/scalingRatio/slowDown/Barnes-Hut 参数、相机缓动、拖拽节点、空白平移、指针锚点缩放、双击复位。
   - 悬停节点及一度邻居高亮，其余元素淡出；提供标题/类型/标签/连接数 tooltip；节点颜色按记忆类型，大小按连接度，标签按缩放阈值和连接度渐显并带 halo。
   - 设置浮层分为 Filters / Display / Forces：类型多选、孤儿节点、共同标签边、节点尺寸、标签阈值、中心/斥力/弹簧/距离参数。
   - 增加合成 3000 节点/6000 边的 worker/synchronous FA2 性能冒烟测试和可复现布局测试。

## 交付与验证

- 修改前先保存本方案；实现后更新 `docs/v1.3.1-图谱重构验收.md`，逐项记录附件参考图校准结果。
- 运行 `npm install`、`npm run check`、`npm test`、`npm run build`、`PYTHONPATH=src python -m pytest -q`、`python -m compileall -q src`。
- 使用清洁环境运行 `scripts/verify-release.ps1`，核对 EXE/API 版本、窗口、技能导入、记忆场景、SHA-256。
- 代码审查重点：不引入未知下载执行、管理员权限、自启动、服务、混淆或持久化；WebGL/Worker 依赖只从 npm 构建进 EXE，Windows 子进程继续使用 `CREATE_NO_WINDOW`。
