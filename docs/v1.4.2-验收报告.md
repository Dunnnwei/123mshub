# 123 MSHub v1.4.2 原生迭代验收报告

> 分支：`native/v2`
> 版本：`1.4.2`
> 验收对象：PySide6 原生壳、file/qrc 图谱岛、v1.4.2 修改清单中的 UI 缺口与图标接线
> 记录日期：2026-09-23（Asia/Shanghai）

本切片只改原生 UI、图谱岛、版本与打包资源，既有服务层仍是记忆/技能仓库的事实源。没有启动 HTTP 服务，没有增加 TCP 监听，没有迁移仓库文件格式；核心服务代码的语义 diff 保持为零。

## 已完成的实现

| 修改清单 | 结果 | 实现与证据 |
| --- | --- | --- |
| 图谱亮暗主题 | [已有] | `GraphBridge.getPalette()` 显式下发画布底色/标签色，Qt 主题信号经 `GraphView` 推入页面；页面使用不透明 hex 混色重算淡出节点、淡出边、焦点边和悬停邻边，页面不再用 `getComputedStyle` 猜背景。 |
| 图谱闲置微动 | [已有] | `web/native-graph/graph.js` 按稳定 id 相位做显示层偏移；单个 `requestAnimationFrame` 只触发 Sigma 重绘，不改 FA2 坐标。拖拽、平移、缩放期间暂停，空闲约 1 秒后恢复；系统减少动态效果、岛内开关以及超过 3000 节点/8000 边时关闭。 |
| 图谱设置面板 | [已有] | 页面内浮层恢复 Filters、Display、Forces 三组控件；类型筛选、孤儿节点、共同标签边、节点尺寸、标签阈值和四个力参数均已接线。`GraphBridge.readGraphSettings/writeGraphSettings` 将 JSON 持久化到当前配置目录的 `native-graph.ini`，不改变核心 `config.json` schema。 |
| 统计与类型 i18n | [已有] | 统计行改为“总数/用户/项目/参考/反馈/本周新增/待收编”，英文统一为 `Total/User/Project/Reference/Feedback/New this week/Inbox`；类型下拉、列表徽章、技能来源和安全页来源同步走原生翻译器。 |
| 记忆编辑窗 | [已有] | 页内详情改为复用的非模态 `QDialog`，默认 `min(1100px, 85% 屏宽) × 75% 屏高`，几何保存到 `native-ui.ini`；列表在编辑时保持可见，正文/预览、frontmatter、双链、AI 描述、保存和软删除仍走原路径。 |
| 技能编辑窗 | [已有] | `MetadataDialog` 改为同一实例复用的非模态窗口，身份、库归属、版本、说明和中文备注表单保持完整，窗口几何持久化。 |
| 空状态与重名跳转 | [已有] | 记忆库和技能库添加引导卡；重名提示包含“打开它”按钮，点击后用既有 `facade.get_entry()` 加载同名条目并打开编辑窗；整理日报保留左历史列表/右内容的双栏查看器。 |
| 123UI v4.2 与品牌 | [已有] | `theme.py` 统一亮/暗 semantic tokens、控件配方、焦点/悬停/滚动条和动效时长；启动时使用亮色 ICO，主题切换换用暗色 ICO；侧栏和关于窗口显示同一图标。 |
| Windows 标识与版本 | [已有] | 启动早期调用 `SetCurrentProcessExplicitAppUserModelID("Dunnnwei.123mshub")`；主窗标题由 `mshub.__version__` 动态生成为 `123 MSHub v1.4.2`；PyInstaller `icon=` 使用亮色 ICO，并随包分发两套 ICO。 |
