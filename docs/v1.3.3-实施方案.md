# 123mshub v1.3.3 实施方案

## 目标与边界

本版本分为两个交付物：

1. `123mshub.exe` 主程序继续自带 Python、FastAPI、前端静态资源和应用运行时，复制后不要求安装 Python、Node.js 或 npm。
2. 新增独立的 Windows 环境依赖包，负责检查并安装 WebView2 Runtime、.NET Framework 4.8 与 Git for Windows。WebView2 用于原生桌面窗口，.NET 4.8 是 pywebview 的 Windows 渲染桥接运行时，Git 用于用户选择 Git 拉取、项目更新和 Git bundle 自愈；默认 archive 模式不强制依赖 Git。

环境包在执行安装前打印系统架构、WebView2、.NET Framework 4.8、Git、默认浏览器和端口状态，明确列出已存在环境与待补充项目；用户确认后才安装。安装器只执行包内、带校验记录和 Authenticode 签名的官方安装文件，不修改应用启动项、不注册服务、不请求应用本体的管理员权限。环境包同时提供说明、清单和可复核的 SHA-256，并使用 WebView2 官方 Evergreen x64 离线安装器，断网时也能完成补充安装。

图谱部分不改后端数据流、组件对外接口或 Sigma/Graphology/FA2 架构，严格落实 `v1.3.3-图谱完善方案.md`：

- P0：用当前画布底色混合生成不透明 hex，替代 Sigma WebGL 中无效的 rgba 淡出；主题变化时重算；悬停邻边使用悬停节点类型色。
- P1：拖拽节点重新加热 FA2，松手后按节点规模重新停表；搜索/类型/孤儿筛选只刷新渲染，不重启布局；边在平移缩放时保持可见，超过 8000 条才隐藏。
- P2：边写入真实 `weight`；斥力单独控制 scalingRatio；连接距离通过反向边权倍率控制；`adjustSizes` 常开。
- P3：搜索未命中节点/边保留空间但变暗；缓存悬停邻居集合；tooltip 依据画布和自身尺寸钳位。

图谱设置（共同标签边、孤儿显示、节点尺寸、标签阈值、四类筛选、中心力、斥力、弹簧、连接距离）写入浏览器 `localStorage`。组件重新进入、刷新或切换页面后读取并继续使用上次值；内部枚举和 API 参数保持不变。

## 发布与验收

- 版本统一提升为 `1.3.3`。
- 前端执行 `npm run check`、`npm test`、`npm run build`；后端执行全套 pytest 和 compileall。
- 对环境安装器执行脚本语法检查、清单校验、报告模式和模拟安装路径测试；不在验收机上静默安装系统依赖。
- 构建 v1.3.3 EXE、便携 ZIP、环境依赖 ZIP，并记录 SHA-256。
- 代码审查确认图谱迭代不新增后端逻辑，不引入 shell、代码混淆、启动项、服务或未知下载执行；环境包下载/安装路径、签名与哈希均在说明中公开。
