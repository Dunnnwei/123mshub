## Windows 安全审查

- 没有新增管理员权限、自启动、服务、持久化、混淆、远程下载执行或未知安装器。
- Git 子进程继续使用参数数组、无 shell，并统一使用 `CREATE_NO_WINDOW` 与隐藏启动信息，避免弹出控制台和被误判为脚本注入。
- Sigma、Graphology 和 ForceAtlas2 仅作为 npm 构建依赖进入内置静态资源，运行时不下载依赖、不启动外部进程。
- PyInstaller warning 文件中的缺失模块均为 Windows 下的可选 POSIX/其他 WebView 平台模块，独立 EXE 实际验证通过。
