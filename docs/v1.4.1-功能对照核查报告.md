## 二、确认缺口（3 项，附补齐路径）

### 缺口 1：空状态引导卡缺失

- **v1.3.3**：记忆库空列表显示引导卡「新建一条记忆，或复制注入提示词发给你的 agent」，
  双按钮分别跳新建表单 / 复制提示词；技能库同理（引导入库）。
- **现状**：`memory_view.py` 全文件无空状态分支（grep「还没有/暂无/empty」均无），空仓库
  打开是一片空白列表。
- **补齐**：列表模型为空时在 `QStackedLayout` 切到引导页（QLabel 说明 + 两个 QPushButton），
  「新建记忆」调既有 `新建` 按钮逻辑、「复制注入提示词」调 `copy_prompt()`——零新服务，
  纯 UI 分支。技能库空状态同理（引导「添加技能 / 程序」）。

### 缺口 2：重名提示缺「打开它」一键跳转

- **v1.3.3**：新建/改名撞库时行内红字 + **「打开它」链接**，点击直接定位并打开同名条目。
- **现状**：有行内提示（memory_view.py:158「已有同名条目；请换一个名称，或打开已有条目」）
  ——但只是文字，没有可点击跳转。
- **补齐**：`collision_label` 改富文本 QLabel + `linkActivated`，信号里调
  `facade.get_entry(name)` 填充编辑器（等价 v1.3.3 的 `openEntryByName` 路径），十行内。

### 缺口 3：日报抽屉的「历史列表 + 内容」双栏结构待落实

- **v1.3.3**：「整理日报」抽屉 = 左侧历史列表（按文件名时间倒序）+ 右侧内容渲染。
- **现状**：「整理日报」按钮存在，但 `memory_facade` 未见 reports 列表/读取方法
  （`tidy_run` 有，`reports_list/reports_read` 无）——若当前只是「跑整理」而非「看历史」，
  则缺这个双栏查看器。
- **补齐**：服务层已有 `GET /api/memory/reports` 等价能力（`TidyService` 的日报落盘
  `memory\reports\`），facade 补两个只读方法（列目录 + 读单文件，注意文件名净化校验，
  服务层已有同款纪律可直接搬），UI 左右 QSplitter。

## 三、待实操核对清单（UI 梳理时对照，附 v1.3.3 判定标准）

这些在代码里有痕迹但交互细节无法静态确认，你实际操作时逐条对：

1. **详情抽屉字段完整度**：v1.3.3 的 frontmatter 表单含 created/updated 只读小字、
   tags 输入（Enter/中英文逗号确认）；核对原生编辑器是否齐全、updated 保存后自动刷新；
2. **放大编辑几何**：v1.2.4 标准 = 放大后 min(1200px, 96vw)、正文 ≥55vh、可还原；
3. **删除二次确认**：软删除前有确认弹窗；批量软删除有确认 + 逐条容错汇总
   （「已 N 失败 M（首个原因）」）；
4. **技能筛选维度**：v1.3.3 = 来源（GitHub/本地）+ 资产类别 + 用户标签 + 「全部/具体标签/
   未标记」快捷筛选 + 标签一键展开收起；核对原生筛选覆盖到哪几维；
5. **技能列表信息列**：更新时间、导入来源、来源徽章（GitHub 绿可更新 / 本地灰 +
   更新按钮置灰带 tooltip）；
6. **列表开屏秒出**：255 技能仓库打开列表不卡（列表不做全量哈希）；
7. **任务面板行为**：安装/更新/扫描转后台不阻塞窗口、进度可见、完成后可看报告、
   按时间倒序、关闭不复活；
8. **语言切换**：设置里切 English/System 立即生效重启保持（i18n.py 已存在，验证生效性）；
9. **主题**：亮/暗切换即时、重启保持、跟随 System 模式生效；
10. **图谱**：与 v1.4.0 验收时一致（悬停聚焦/拖拽弹簧/设置持久），并核对主题切换时
    图谱配色跟随；
11. **导入流程完整度**：扫描预览报告明细（记忆/技能识别 + 来源分类）→ 确认 → 后台进度
    → 完成报告（导入/跳过/失败明细 + 自动日报）；重复导入幂等提示；
12. **设置草稿模型**：改了不点保存不生效；代理检测只填草稿。
