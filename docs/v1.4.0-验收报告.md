# 123 MSHub v1.4.0 原生壳验收报告

> 验收日期：2026-09-23  
> 分支：`native/v2`  
> 代码基线：v1.3.3（原有 174 项服务层测试）  
> 架构文件：[v1.4.0-技术架构.md](v1.4.0-技术架构.md)

## 结论

v1.4.0 原生壳 MVP 的实现切片已完成：原生主窗、记忆库 CRUD、软删除、投递箱、设置、主题、延迟图谱 web 岛、PyInstaller onedir 和构建冒烟路径均已落地。技能库、安全中心及 v1.6.0 原生红利项按总体方案留在后续里程碑，没有用占位页面伪造完成度。

数据兼容和功能自动化检查通过；Windows 本机冻结包可以在 `file://` 图谱页中加载 Qt WebChannel 并正常退出。内存验收需要按架构约定分口径看：Private Bytes 达到 200 MB 内，工作集实测约 237.64 MB，作为下一轮优化/长期观察项保留。

### 图谱构建与本地协议

执行：

```powershell
& .\web\node_modules\.bin\vite.cmd build --config .\web\native-graph\vite.config.mjs
```

结果：通过。构建产物包含 `index.html`、CSS 和单一 JS bundle；Vite 插件补回 Qt 运行时提供的 `qrc:///qtwebchannel/qwebchannel.js`。静态测试确认图谱资源中无 `http://` 或 `https://` 引用。

运行时检查：

- 页面通过 `QUrl.fromLocalFile()` 加载；
- `_LocalOnlyInterceptor` 只放行 `file/qrc/blob/data/about`；

- 没有为了规避 CORS 启动本地 HTTP 服务；
- 图谱 web view 只在第一次点击“记忆图示”时创建。

### 内存口径

在 Windows 图形平台、未打开图谱页、真实 `D:\MSH` 配置下采样主进程：

| 指标 | 结果 | 口径 |
|---|---:|---|
| Private Bytes | 126.83 MB | 主 Python/Qt 进程，≤200 MB |
| Working Set | 237.64 MB | 主进程驻留集，超过 200 MB 目标，列为优化项 |
| Chromium renderer/GPU/profile | 未并入上表 | 图谱页打开时单独采样 |

这组数字遵循架构文件的分层口径，没有把 WebEngine 子进程内存隐藏到主进程数字里，也没有把 Private Bytes 冒充 Working Set。
