# 123 MSHub v1.10.0D Stitch 全页面重构实施方案

日期：2026-10-01  
基线：`release/native-v1.10.0` → 当前源码中的 v1.10.0C 界面工作树  
目标交付：`release/native-v1.10.0D/` 与 `123mshub-native-v1.10.0D-win64.zip`

## 目标与边界

本轮沿用 PySide6 原生壳、MemoryFacade、任务队列、SQLite/文件协议和本地 QWebEngine 图谱，不迁移框架、不改变仓库数据格式、不删减已有入口。改动集中在共享视觉层、各页布局的统一和发布资源，所有现有功能（记忆增删改、投递箱、整理、图谱、技能安装/更新/安全检查、设置/导入/升级、语言和主题）继续使用原有服务方法。

Stitch 只提供了“记忆仓库”页面，因此把它提炼为跨页面规则：左侧品牌与五项导航、页头眉标/标题/副题/动作组、统计与筛选工具带、表格卡片、紧凑后台任务卡和底部状态。技能仓库与安全中心沿用同一页头和表格比例；记忆图示把 Web 图谱嵌入同一页头与画布卡；设置页把三组配置保留在同一页头下的标签卡中。亮色使用 Silk 的冷灰粘土表面，暗色使用同一层级关系的深海军蓝 Mica 表面；颜色只替换令牌，不复制两套业务布局。

## 共享设计令牌

- 亮色：画布 `#E8EAF0`、侧栏 `#E5E7ED`、内容面 `#F0F2F8`、凸起面 `#FFFFFF`、内嵌面 `#E9ECF3`、墨色 `#2E3040`、靛蓝动作 `#6366F1`、紫罗兰强调 `#7C3AED`。
- 暗色：画布 `#0B0E14`、侧栏 `#0E172A`、内容面 `#131B2E`、凸起面 `#1A243D`、内嵌面 `#0F1830`、浅墨色 `#DAE2FD`，动作仍为靛蓝并提高文字对比。
- 四类颜色固定为用户/蓝、项目/紫、参考/青绿、反馈/红；记忆胶囊、表格、图谱节点和图例共用同一 token 键。
- 控件圆角分为 12px（控件）、16px（页头/卡片）和胶囊；阴影使用背景色调，交互只动画 `transform`/`opacity`，按下态有轻微压感。
- 字体优先使用已打包的 `Dream Han Sans CN`，缺失时回退系统中文字体；等宽数字用于时间、统计和版本信息。

## 页面映射

| 页面 | Stitch 结构落点 | 功能保持清单 |
|---|---|---|
| 记忆仓库 | 统计筛选带 + 记忆表格卡 + 编辑详情 | 全文搜索、类型/排序、投递箱、批量分类/标签/AI/软删、Shift 连选、编辑/预览/软删/硬删/保存、整理与日报 |
| 记忆图示 | 同一页头 + 搜索/设置/图谱画布卡 | 节点筛选、标签边、孤儿节点、闲置微动、布局参数、缩放/复位、节点浏览、打开记忆、WebChannel |
| 技能仓库 | 同一页头 + 搜索过滤 + 数据表格卡 | 添加、编辑、离线检查/AI 检查、更新、翻译、复制提示词、批量删除/信任/更新、Shift 连选 |
| 安全中心 | 路线选择 + 检查工具带 + 安全表格卡 | Route A 离线、Route B AI、批量检查、信任选中、隐藏已通过、报告详情、批量删除/Shift 连选 |
| 设置选项 | 页头动作 + 三标签配置卡 + 固定保存区 | 仓库/语言、AI/凭据、维护/导入、代理检测、模型拉取、密钥状态、清除、升级检查、自动检查开关 |

## 实施顺序

1. 记录 v1.10.0C 源码与发布包基线，读取模板截图、`DESIGN.md`、`uicode.md`，建立本方案和功能矩阵。
2. 以 `design_tokens.json` 为单一配色源，修正 Qt QSS、图谱 CSS、图谱 palette、导航/选中态和分类映射；补齐图谱页页头，使五页共享同一结构。
3. 调整控件密度和状态：页头高度锁定、列表列宽可收缩、表格行高可读、空/加载/错误状态有明确占位、任务面板不遮挡五项导航。
4. 运行编译、全量 pytest、Web 检查和 native graph 构建；使用离屏样本分别检查五页亮色、五页暗色和紧凑窗口。
5. 从最终源码构建 PyInstaller onedir，检查图谱资源、字体/图标、QtWebEngine 资源、版本和零监听 smoke；生成 EXE/zip SHA256 与交付说明。

## 验收矩阵

- 功能：全量 pytest；native 视图逐页构造；关键编辑/删除/主题切换回归；图谱首次进入只初始化一次。
- 视觉：亮色/暗色截图包含记忆、图谱、技能、安全、设置五页；检查页头、侧栏、选中态、表格、空态、任务卡和按钮动效令牌。
- 资源：Vite native graph 构建输出复制到 `src/mshub/native/graph/assets`；包内 `design_tokens.json`、graph `index.html`、WebEngine 资源和品牌图标存在。
- 运行：最终 EXE 使用临时配置与真实 `D:\MSH` 图谱 smoke；确认没有 TCP 监听、图谱节点/边真实加载、闲置微动继续推进。
- 交付：`release/native-v1.10.0D/123mshub/`、`README-完整包.txt`、`SHA256SUMS.txt`、完整 zip、发布说明和 QA 记录；旧 v1.10.0/C 目录保留可回退。

证据边界：离屏截图只证明 Qt 布局和令牌落地，不代替 Windows 屏幕、DPI、真实供应商响应或用户 GPU 帧率验收；这些项目在 QA 中分别标注。
