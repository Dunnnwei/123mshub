# 123MSHub v1.10.1 视觉与功能迭代实施方案

## 目标

在 v1.10.0D 的功能、路由、仓库数据结构和原生桌面交互基础上，完成模板化视觉收口，并保留亮色与暗色两套主题。此次版本聚焦字体层级、侧栏信息密度、品牌图标、圆角语言、图示页阅读性、后台任务状态反馈和导入去重。

## 设计决策

### 字体与层级

- 运行时使用 Qt 应用的系统默认字体作为首选字体，保留 Windows 常见字体作为回退，不再依赖 Dream Han Sans CN 的字体文件注册。
- 正文、表单和内容列表保持 12px；侧栏五组主功能提升到 13px 并使用粗体；侧栏计数使用 10px、常规字重；辅助信息使用 10–11px。
- 页面标题、品牌字标和操作按钮继续使用既有设计令牌，通过字号和字重形成“标题—主体—辅助”三级层次，避免仅靠颜色区分。

### 侧栏与品牌

- 五组主功能继续使用原有路由和图标，改为可对齐的行组件；记忆仓库、技能仓库、安全中心的数量从现有页面数据实时汇总并靠右显示。
- 主项目 logo 使用 `NEWmshublogo.svg`；关于弹窗额外展示 `new123uilogo.svg` 与主 logo 并列，并标注“123系列工具”。两个 SVG 均生成 Windows 多尺寸 ICO，运行时和 PyInstaller 均使用 ICO。

### 圆角与动效

- 版本胶囊、功能眉标、统计按钮、设置页签统一采用高圆角，沿用主题 token 的边框和填充。
- 后台任务图标是任务运行状态的反馈：存在未完成任务时持续旋转，全部完成后停止并回到初始角度。展开状态箭头向下，收起状态箭头向上且垂直居中。

### 图示页

- 页面语义由“共享关系”改为“记忆关系”。
- 删除“键盘浏览节点”辅助文字；节点浏览器缩小并置于左上角，减少对关系图的遮挡。
- 节点颜色按信息量分层：主量级使用 `#6366F1`、`#7C3AED`，少量类别使用亮红和亮绿；暗色主题的连线提高一档对比度。

### 导入去重

- 记忆的稳定身份为规范化名称（去首尾空白、统一大小写、统一路径分隔符）；同一导入批次和目标仓库已有同名项均跳过，不覆盖既有内容。
- 技能的稳定身份为“技能库/来源范围 + 规范化名称”；目标仓库已有同身份项或同批次重复项均跳过，不覆盖既有内容。
- 导入报告明确区分新增、跳过重复和失败数量；原有导入错误处理和取消行为保持不变。

## 实施顺序

1. 更新版本号、设计令牌、字体解析和图标资产，保证源代码与打包入口使用同一资产。
2. 改造主窗口侧栏、数量、品牌弹窗和后台任务状态组件。
3. 统一圆角样式并调整图示页文案、节点浏览器和颜色对比度。
4. 在导入服务层实现确定性去重，补充单元测试和 UI 反馈。
5. 更新发布说明，执行 Python 全量测试、Web 检查与构建，完成隔离冒烟和真实 `D:\MSH` 图示冒烟。
6. 重新计算发布包 SHA-256，输出 `release/native-v1.10.1` 和对应 Windows ZIP 及验收记录。

## 验收边界

- 自动化测试只证明代码路径和隔离环境行为；真实 Windows UI、真实仓库数量和图示动画以最终 EXE 冒烟结果为准。
- 发布包、ZIP、哈希和验收文档必须来自同一次最终构建；构建后任何资源修改都必须重新打包和计算哈希。
