# 123mshub v1.11.1 验收报告

日期：2026-10-03。基线：v1.11.0；目标：本地来源、命名、AI说明与仓库连选状态迭代。

## 交付结论

v1.11.1 已完成源码迭代并生成单一完整 Windows onedir 包。现有 PySide6 原生页面、技能/记忆/安全仓库读写协议、后台任务、离线安全检查、本地图谱 file/qrc 资源和 123ui5.0 视觉令牌保持不变。

## 需求验收

- 添加技能 / 程序：来源输入支持 GitHub URL、owner/repo、本地目录与 `.zip`；浏览入口可选择 ZIP。新增独立“命名”栏；本地来源的路径仅用于读取，命名决定条目身份和本地目录。命名在预览和后台入库共用校验，拒绝路径分隔符、点开头、Windows 非法字符、保留设备名和尾部空格/句点。
- 本地安全入库：目录先复制到临时快照；ZIP 拒绝越界路径、符号链接、重复路径、超过 20,000 个成员或 500MB 解压内容；之后继续复用解析、标准/全仓安装、离线扫描、manifest、SQLite 和 index 事务。
- 技能编辑信息：自动翻译按钮前新增“AI说明”。后台读取当前条目的 SKILL.md/README 等本地材料，通过设置中的 OpenAI 兼容 AI 网关生成中英文推荐说明，分别填入中文/英文栏，覆盖旧内容但由用户检查后点击“保存”。请求按技能复合身份和编辑会话绑定，过期响应不会写入新条目。
- 技能仓库：批量操作行删除重复的“已勾选条目：”。
- 记忆仓库：底部增加与其他页面一致的“已连选第 X–Y 行（共 N 项）”状态文字；右侧保留 Shift 连选操作提示。

实施记录：[v1.11.1-实施方案.md](../v1.11.1-实施方案.md)。
