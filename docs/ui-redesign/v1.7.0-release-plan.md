# v1.7.0 发布收口计划

依据：已确认的 frontend-design 方向及 `design-system/123mshub-native-v1.7.0/MASTER.md`。

1. 修正当前实现与 MASTER 的差异：真实字体字重、选中态、紧凑页头、键盘入口、异步详情与完整操作入口。
2. 所有产品版本统一为 1.7.0；更新发布说明与本地启动指引，保留 v1.6.1 成品供回退。
3. 修正 PyInstaller 的 design_tokens.json 收录，构建前校验图谱入口与版本，记录完整资源哈希。
4. 验证行为：记忆新建/编辑/软删除、未保存保护、加载反馈、技能详情/提示词、安全报告、设置草稿、主题与语言、图谱 WebChannel 与键盘入口。
5. 在 Windows Qt 平台验证浅/深主题、紧凑/标准/大屏及 125%/150% 缩放，记录隔离样本和真实数据副本的区别。
6. 执行全量测试、Web 检查和图谱构建；生成 native-v1.7.0 onedir，验证冻结启动、图谱、零 TCP 监听及最终 SHA256。

本地交付范围不包含远端 GitHub 发布、在线供应商计费测试或修改用户生产仓库。应用功能与既有数据协议保持兼容。
