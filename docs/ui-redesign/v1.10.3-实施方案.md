# 123 MSHub v1.10.3 迭代实施方案

日期：2026-10-01
基线：v1.10.2 原生 PySide6 桌面包
目标：修复安装失败与错误打开、补齐标签工作流、统一列表信息层级与悬停摘要、纠正安全中心计数、完善后台任务失败处置，并以 mattpocock/skills 的 engineering/code-review 与 anthropics/skills 的 frontend-design 完成代码/UI 复核。

## 产品与设计约束

123 MSHub 面向需要在本地维护共享记忆和可复用技能的 Agent 使用者。高频任务是“找到条目—确认来源与安全状态—打开或编辑—批量维护”。列表中的来源、标签、说明和安全状态必须可以在不打开详情的情况下被快速比较；失败操作必须说明原因并给出可重复动作。沿用 v1.10.2 的 PySide6 Widgets + QWebEngine 本地架构、现有路由/服务/存储协议、靛蓝/紫罗兰主题与浅染选中态。

悬停摘要采用统一的可换行矩形小圆角提示：第一行显示标签，后续显示说明；最大宽度 420px，按内容换行，避免一行横向延伸。表头使用 #6366F1 / #7C3AED 主题色，列表内容左对齐（时间等必要数据保持可读的固定列）。

## 执行顺序

1. 先修存储边界和选中身份：安装失败清理/缺失目录过滤、当前行取值、不可打开提示。
2. 接入标签字段与来源文案映射。
3. 重排技能/安全列表列，加入 RichHoverTooltip，统一表头色与对齐，移除选中竖条。
4. 增强 JobController 的详情/重试交互与红色状态。
5. 更新版本面、测试、发布说明和验收记录，运行全量 pytest、前端检查、PyInstaller onedir 与真实仓库 smoke。
6. 以两个指定技能做代码和 UI 复核；发现的问题直接修复，复核结果写入验收记录。
