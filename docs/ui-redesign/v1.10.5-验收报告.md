## 五项需求核对

1. **后台任务**：`MainWindow` 初始 `_jobs_collapsed=True`，启动时只保留标题行；从无任务到首个任务的状态转换自动展开，默认面板高度为 216px，可容纳四个 32px 任务行和操作行。任务标题、活动图标、箭头、任务容器及操作行使用透明背景；收起/展开箭头的 hover、pressed、checked、focus 均无边框。
2. **字号统一**：`ListTableDelegate` 使用 `TYPOGRAPHY` 的 pixel size 绘制名称 12px、说明和元数据 11px，避免 `QFont(..., pointSize)` 在 Windows DPI 下放大；与记忆行 `rowTitle/rowDesc/rowCol` 对齐。
3. **搜索图标**：`decorate_controls` 给记忆和技能搜索框挂透明 `QToolButton#searchLeading`，通过 resize/show 事件将其 y 坐标放在输入框内容中心，文本左边距统一为 28px；输入、清除和 Ctrl+F 回归通过。
4. **选中/焦点**：记忆列表移除 accent 焦点外框，仅保留整行选中浅染；设置页和编辑弹窗的输入焦点边框未改。选中行 alpha 从亮色 30/暗色 46 提高为 64/72，截图中亮暗对比明确。
5. **背景色**：`design_tokens.json`、theme fallback、starfield 默认值及 native graph CSS/HTML 均同步为亮色 `#E5E5E7`、暗色 `#18181B`；主题检测改为读取当前 token，不依赖旧色值。
