# v1.10.4 代码与 UI 审查记录

日期：2026-10-02。审查基线：`v1.10.3`（`fb2d8b9`）。

本轮代码审查按 `engineering/code-review` 的 Standards / Spec 两条轴执行，UI 审查按 `frontend-design` 的主题令牌、层级、状态反馈和实际渲染检查执行。变更限定在 `src/mshub/native/`、测试和发布文档；没有引入 TCP/localhost 渲染服务，也没有改动 `src/mshub/` 核心仓库协议。

## Standards

- 仓库没有 `CODING_STANDARDS.md`、`CONTRIBUTING.md`、`AGENTS.md` 或独立 lint 配置。架构约束来自《v1.4.0-技术架构》和《v1.4.0-原生化总体方案》：核心业务保持稳定，原生适配层负责 Qt 展示，本版符合这一边界。
- 外部表头镜像内部表头属于为“表头独立、滚动条从表头下开始”服务的适配封装；已补初始化同步保护、隐藏列同步、滚动偏移、缩放和外部拖列宽回归。
- 任务重试只有 `JobController` 一个注册入口。安装任务不再保留单独闭包；重试白名单覆盖安装、升级、翻译、保存、检查、信任、导入和整理，删除操作不自动重试。

## Spec

- 亮/暗主题摘要窗口使用 `current_palette()` 的 `raised`、`ink`、`line`，并以纯文本换行显示。
- 任务面板的按钮、折叠高度、拖拽锁定、任务 ID 选择、详情和失败重试均有对应实现；成功任务详情保留，只有错误任务启用重试。
- 技能与安全表格共用 `ListTableCard` 和 `ListTableDelegate`：圆角外框、独立主题色表头、表头下滚动、名称/说明双行、整行选中和悬停反馈；说明列保留为隐藏数据以维持排序和兼容性。
- 记忆页三枚头部按钮统一尺寸；技能编辑窗口按用户确认的“四个长字段整行 + 四个短字段两行两列”重排，页脚三按钮等尺寸靠右。

## UI 检查

使用 Qt offscreen 在亮色和暗色主题分别渲染技能/安全列表，检查了：

1. 表头标题均为 `#6366F1` 主题色；外框圆角没有被表头方形背景盖住。
2. 右侧滚动条从表头下方的数据区开始；窗口缩放、外部表头拖列宽不会把用户宽度重置。
3. 选中行只显示整行浅染；失败/未完成任务使用错误色，完成后恢复正常文字色。
4. 摘要提示在亮色为 `#FFFFFF/#2E3040`，暗色为 `#1A243D/#DAE2FD`，标签和说明均可换行。
5. 编辑技能信息页的长字段、2×2 元数据和页脚按钮在实际布局中可见，没有只占左侧的空白表单行。

截图与脚本放在同目录的 `v1.10.4/` 子目录。offscreen 证据用于回归布局；最终 EXE 的 Windows 图谱 smoke 与包校验另见验收报告。
