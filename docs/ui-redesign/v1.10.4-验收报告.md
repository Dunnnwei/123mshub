## 七项指令核对

1. 摘要窗口读取当前主题令牌；亮色使用浅色表面和深色文字，暗色使用深色表面和浅色文字，标签和说明均可换行。
2. 后台任务的“详情 / 重试 / 清除已完成”共享字号、字重、颜色、尺寸、手型光标和显示条件；无任务或折叠时隐藏，折叠高度锁定，展开后恢复拖动高度。
3. 任务标题、图标和箭头按折叠/展开状态分别对齐；任务选择按任务 ID 保持；详情可查看成功、运行中和失败任务；安装、升级、翻译、保存、检查、信任、导入和整理等可重提任务从提交快照重试，重新进入红色进度态。
4. 三个列表底部提示统一为“`双击可打开编辑  ·  可使用 Shift 连选`”，英文界面有对应词条。
5. 技能仓库和安全中心复用记忆仓库的圆角卡片、独立表头、表头下滚动区和整行选中态；名称列显示名称与说明双行，说明字段保留为隐藏可排序数据，不再绘制逐列竖条纹。

7. 技能编辑窗口按确认方案排列：四个长字段整行，来源类型/所属库与版本/标签两行两列；底部说明在左，自动翻译/保存/关闭三枚等尺寸按钮靠右。
