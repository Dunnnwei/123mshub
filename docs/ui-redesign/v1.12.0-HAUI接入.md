# HAUI 原生适配

HAUI 0.1.0 是 React 组件系统；123 MSHub 桌面应用使用 Qt 原生交互。此版本复用 HAUI 的真实主题解析、视觉规范、Tabler 图标与字体，使用 Qt 控件适配其外观，没有引入第二套业务 UI 或用 React 重写存储与后台任务。

## 可复现的同步

在本机 HAUI 项目运行 `npm run build:lib` 后，在本仓库运行：

```powershell
node scripts/native/sync-haui.mjs D:/DiskWork/PJ/HAUI
# 仅维护者生成字体时需要 fonttools[woff]；用户运行无需这些工具。
.venv/Scripts/python.exe scripts/native/sync-haui-fonts.py
```

提交生成的 `src/mshub/native/haui/` 和图谱展示文件。HAUI 源文件与输出 SHA256 见 `haui/manifest.json`。发版不重新拉取 HAUI，也不依赖其绝对目录。

## 适配契约

- 12 套调色板 × 2 种外观 × 默认/8 种强调色；数据全部经过 HAUI `accentedPalette`，保留完整 26 字段及回落结果。
- Qt 的 `bg/ink/line/selection/control` 来自 HAUI 背景、可读文字及 3/4/5/6/8/10/24% 派生规范。HAUI `native.qss` 只负责控件映射。
- palette、light/dark/system、accent 独立保存于原 `native-ui.ini`，继续识别旧 `theme` 字段。
- 正文为系统字体；标题使用随包 Space Grotesk，代码使用 JetBrains Mono。字体从 HAUI 自带 WOFF2 转为 Qt 可读 TTF，原文件和 OFL 许可一起分发。
- 导航、按钮、搜索使用 HAUI 导出的 Tabler 图标。操作系统文件选择器保持原生。
- 图谱保留 v1.11.4 的 Sigma/Graphology JS。`haui.css`/`haui.js`/`haui-tokens.js` 只适配视觉、图标、字体和完整主题变量，沿用 QWebChannel，无远程字体或 TCP 服务。
- 旧 `mshub.ui5` 模块保留给旧 API/旧网页消费者兼容，桌面入口不再从它读取主题。

## 验证边界

这是 HAUI 的 Qt 外观适配，不是 React/Radix 原语运行时，也不承诺 Qt 与 CSS 子像素渲染逐像素一致。桌面最小逻辑尺寸 960×640，验证亮/暗、125%/150% 缩放、键盘焦点及实际图谱；手机视口不适用于这个桌面程序。
