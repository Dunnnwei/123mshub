## 视觉核验

- 设计先行记录：[Hermes-Mono-Clean-UI规范](Hermes-Mono-Clean-UI规范.md)。来源为本机 Hermes Agent：`apps/shared/src/theme-presets.ts`、`apps/desktop/src/themes/context.tsx`、Desktop/Web Mono preset 和 `hermes_cli/skin_engine.py`。
- Qt 令牌：亮色 `#FFFFFF / #F5F5F5 / #F9F9F9`，暗色 `#0E0E0E / #0A0A0A / #141414 / #1E1E1E`；主动作 `#9A9A9A`，亮/暗选择 `#D8D8D8 / #505050`，风险 `#B94A3A / #A84040`。
- 任务面板默认收起、首任务自动展开；标题/活动图标/箭头/任务容器无额外背景层，箭头焦点不绘制第二层边框。
- 记忆、技能、安全列表使用整行灰阶选择；记忆列表自身焦点框取消；设置与所有编辑输入保留边框焦点。技能/安全委托字号与记忆列表共享。
- 搜索框放大镜使用独立透明前缀控件，按编辑框实际高度重算，中心误差通过 v1.10.5 回归测试约束为 ≤1px。
- Qt、保留 Web UI 和本地图谱岛取消蓝紫渐变、彩色类别、玻璃/阴影装饰与圆角表面；仅滚动条把手保留 2px 操作圆角。
