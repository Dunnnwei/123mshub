# v1.10.5 UI 视觉状态与主题底色收口实施方案

日期：2026-10-02。基线：v1.10.4。目标：在保留 PySide6 Widgets、QWebEngine/QWebChannel、本地文件资源、仓库路径和存储协议的前提下，完成五项原生 UI 细节修正并按 `release/` 单一完整包惯例交付。

## 目标用户与界面语义

123 MSHub 的主要使用者是需要快速浏览、筛选和编辑本地记忆与技能资产的 Agent 用户。记忆列表是目前最稳定的阅读基准：标题使用 12px、摘要与元数据使用 11px，行选中只表达“当前目标”，不把焦点框误读成第二种选中状态。技能仓库、安全中心和后台任务都属于高频操作区，视觉反馈应轻量、可比较、能在亮暗主题中保持一致。

本版继续使用现有系统字体、靛蓝/紫色动作色和 Silk/Mica 层级，仅收口底色、字号、焦点边框和后台任务状态；不改变业务动作、页面路由、数据协议、任务重试、列表排序或编辑保存行为。

## 技术决策

1. **后台任务**：初始化为收起状态；第一次出现任务行时自动展开，并把任务面板目标高度设为“标题、4 行任务、操作行和内边距”的固定约 216px，仍允许用户随后拖动。收起时保留标题行，空任务不自动展开。标题、活动图标、箭头按钮以及任务卡不再绘制额外填充背景；箭头保留无边框的 40px 左右点击区域。
2. **列表字号**：`ListTableDelegate` 改用像素字号而非 Qt 的 point-size 构造，名称/说明分别绑定 `TYPOGRAPHY["row"]` 与 `TYPOGRAPHY["meta"]`。这样技能仓库与安全中心的实际屏幕像素和记忆仓库一致，避免 DPI 下 point-size 放大。
3. **搜索图标**：将搜索前缀图标封装为透明、可垂直居中的 leading widget，保留现有清除按钮；使用统一的文本边距，图标中心相对输入框内容区居中，不改搜索信号与快捷键。
4. **选中与焦点**：记忆列表取消 `:focus` 外框；后台任务箭头取消 `:focus` 外框和按下背景。设置页输入控件及所有编辑/详情弹窗的输入焦点边框继续保留。列表选中继续使用整行主题色浅染，并把选中染色 alpha 从 30/46 提高到 64/72，增强亮暗主题对比。
5. **主题底色**：亮色画布改为中性浅灰 `#E5E5E7`，暗色画布改为中性深灰 `#18181B`。`current_palette()` 与记忆分类色读取统一通过主题 token 判断，避免依赖旧颜色字符串。

## 需求到验收矩阵

| 编号 | 实现位置 | 验收证据 |
| --- | --- | --- |
| 1 | `main_window.py` 任务初始状态、首个任务自动展开、四行高度；`theme.py` 任务层透明和箭头无焦点框 | 空任务启动收起；提交任务后自动显示；有 4 行时高度可容纳；亮暗截图检查标题/图标/箭头无额外底色；箭头点击后无边框 |
| 2 | `list_table.py` 委托像素字号；共享 `TYPOGRAPHY` | 技能、安全、记忆列表的标题/说明字号均为 12px/11px；离屏几何与字体断言通过 |
| 3 | `ui_icons.py` 搜索 leading 控件 | 记忆与技能搜索框图标中心 y 与输入框内容中心差值不超过 1px；输入、清除、Ctrl+F 行为回归通过 |
| 4 | `theme.py` 焦点选择器、选中 alpha；`main_window.py` 箭头属性 | 记忆列表取得焦点时 listCard 外无新增 accent 边框；编辑弹窗输入框仍有 accent 边框；选中行亮暗颜色差异增强 |
| 5 | `design_tokens.json`、`theme.py` 兜底、`starfield.py` 默认值 | 亮色背景 token 为 `#E5E5E7`，暗色为 `#18181B`；两种主题可应用，图谱画布跟随 token |

## 验证和交付顺序

先运行定向 native 回归和离屏双主题几何检查，再运行全量 pytest、前端检查和 PyInstaller 单一完整包构建。源码冻结后重新执行最终 EXE smoke（隔离配置、真实 `D:\MSH`、零 TCP 监听、图谱节点和动画状态）、ZIP CRC/包内 EXE 哈希比对，并生成 `release/native-v1.10.5/`、完整 ZIP、README、`SHA256SUMS.txt`、发布说明和验收报告。离屏截图、最终 EXE smoke、包校验和实体桌面人工验收分别记录；没有实际执行的桌面/DPI/用户验收标为 `[待核]`。
