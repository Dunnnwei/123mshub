- 图谱页面同步 token、字体、焦点状态和 reduced-motion；增加可键盘浏览的节点下拉列表与“打开”按钮，作为 canvas 的等价入口；保留 Sigma 搜索、筛选、孤儿节点、共同标签边、力参数、缩放、复位和本地 WebChannel。

## 可访问性核对

遵循已安装的 Vercel Web Interface Guidelines：语义原生控件、表单标签、图标按钮 aria-label、可见 focus-visible、异步状态 live region、reduced-motion、长文本可访问全文。图谱 `message` 使用 `role=status`/`aria-live=polite`；Web 控件使用 `:focus-visible`；Qt 控件使用原生 StrongFocus 与 QSS 2px focus 边界。`outline:0` 仅出现在搜索输入，父级 `:focus-within` 提供替代焦点环。
