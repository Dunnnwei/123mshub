# v1.10.2 侧栏图标与技能表格交互修复

## 范围与已复现原因

本版以当前 v1.10.1 工作树为基础，保留系统字体、主题、数据服务、导入去重和配置行为，只修复侧栏图标与技能列表列宽交互，并同步版本与本地完整包。

1. `NavigationDelegate` 中 `icon = opt.icon` 引用的是 PySide6 样式选项内的可变图标对象；随后清空 `opt.icon` 导致该引用也为空。已通过最小 Qt 程序复现：清空前 `isNull=False`，清空后引用 `isNull=True`，显式 `QIcon(opt.icon)` 副本保持非空。
2. Stitch 稿 `stitchuirb/uicode.md` 中五个导航符号依次为 Material Symbols Outlined 的 `neurology`、`hub`、`auto_awesome`、`shield`、`settings`。将相同符号的官方 SVG 轮廓内置为本地资源，并按亮暗主题/选中状态染色，不引入字体或在线加载。
3. `_SkillTable.resizeEvent` 会重新设定各列宽度并把说明列设成 `Stretch`，导致部分列不能自由调整、窗口缩放后手调宽度丢失。Qt 默认的列宽拖动也仅限表头边界。

## 实现约定

- 保留图标副本再绘制行背景，图标按当前 DPI 输出；保持现有文字字号、字重与右侧计数。
- 技能列表全列采用 `Interactive` 调整模式，固定可见表头，不再因窗口较窄隐藏标签和更新时间；较窄时使用横向滚动。
- 每个可见列的右边界设置贯穿列表视口高度的窄拖动区，覆盖有数据行和下方空白区；悬停显示水平调宽光标与轻量强调线。
- 边界拖动消费自身鼠标事件，避免误触勾选、排序或详情；表头排序、全选、条目双击、Shift 多选仍走原逻辑。
- 首次展示按可用宽度布置默认列宽；第一次手动调整后保持用户选择，刷新、主题切换、窗口缩放、页面切换不重置。
- 只新增针对失效根因及真实鼠标交互的回归用例，验证亮暗/高 DPI 图标有像素、列边界拖动、滚动后坐标、宽度保持、排序与选择不受影响。
