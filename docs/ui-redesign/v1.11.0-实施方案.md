# 123mshub v1.11.0 / 123ui5.0 实施方案

日期：2026-10-03。基线：v1.10.6 Hermes Mono Clean。

## 目标

本版把 Hermes Agent 的 Mono Clean 视觉逻辑保留为 123mshub 的结构基线，再把品牌强调层改为两枚可复用的主题种子：

- Indigo：`#6366F1`，用于主要动作、选中指示、图谱主线和第一层品牌强调；
- Violet：`#7C3AED`，用于次级强调、类别区分和渐变终点。

两枚颜色通过 `123ui5.0` 令牌源派生为亮色/暗色表面、文字、边框、选择态、语义态和图谱态。背景仍保持 Hermes 的克制灰阶，避免为了换品牌色而改变已经稳定的页面层级、密度和可读性。

## 先行代码与配置核对

已核对本机 Hermes Agent：

- `apps/shared/src/theme-presets.ts`：Mono preset 的语义颜色和动效基线；
- `apps/desktop/src/themes/context.tsx`：`seed → mix → derived tokens` 的亮色推导、可读前景色和 sidebar 派生；
- 123mshub：`src/mshub/native/theme.py`、`src/mshub/native/design_tokens.json`、`web/src/styles.css`、`web/native-graph/style.css`、`web/native-graph/graph.js` 和 QWebChannel 图谱桥接。

Hermes 的逻辑是“一个主题种子驱动一组语义令牌”，不是让所有 UI 都直接使用同一枚颜色。破坏性错误、成功、警告、正文和表面仍保留各自令牌；本版只让品牌强调层共享 Indigo/Violet 的派生关系。

## 令牌架构

`design-system/123ui5.0/` 是可审阅的规范与导出包，`src/mshub/ui5/` 是运行时可直接导入的 Python API，`web/src/ui5/` 是 Web/Vite 可直接导入的 JavaScript API。`src/mshub/native/design_tokens.json` 保留为发布包中的兼容镜像，并由测试验证与 123ui5.0 源一致。

令牌分三层：

1. primitive：Indigo、Violet、灰阶、语义颜色和动效常量；
2. semantic：`bg`、`surface`、`ink`、`action`、`accent`、`selection`、`graph_line` 等页面语义；
3. component：按钮渐变、列表选择填充、焦点边框、图谱节点和任务面板状态。

## 视觉边界

- 表面、列表、弹出层继续使用 Hermes 的实色平面和 0px 结构边界；不恢复玻璃模糊、阴影或大圆角。
- 主要 Agent 入口和品牌动作使用 `#6366F1 → #7C3AED` 的短渐变；普通按钮、输入框和列表仍使用单色令牌，避免整页彩色化。
- 记忆/技能/安全列表的整行选中继续使用背景填充；设置和编辑控件继续使用边框焦点；列表容器、后台任务箭头不新增焦点边框。
- 图谱节点按四种业务类型使用 Indigo/Violet 的明度阶梯，连接线保持低对比度；动效和布局参数不改。
- 亮暗模式沿用 v1.10.6 的字号、间距、任务面板自动展开和搜索图标居中规则。
