# 123mshub v1.11.0 验收报告

日期：2026-10-03。基线：v1.10.6 Hermes Mono Clean。验收范围覆盖 123ui5.0 Indigo/Violet 主题系统、原生业务功能、本地图谱资源、可复用 UI 系统包和最终 Windows 完整包。

## 结果

v1.11.0 已完成并生成单一完整 Windows onedir 包。Hermes Mono Clean 的结构、字号、间距、平面表面、选择/焦点分工、任务面板行为、搜索图标定位、页面路由、仓库读写协议、QWebChannel 和图谱动效均保留；品牌强调层统一使用 `#6366F1` Indigo 与 `#7C3AED` Violet。

`123ui5.0` 已成为可直接调用的独立 UI 系统：

- Python：`from mshub.ui5 import theme_tokens, action_gradient`；
- Web：`import { themeTokens, actionGradient } from './ui5/tokens.js'`；
- 规范与导出：`design-system/123ui5.0/`；
- 独立包：`release/123ui5.0.zip`，哈希记录在 `release/123ui5.0-SHA256.txt`。

## 视觉实现

- 亮色和暗色继续使用 Hermes 的 `#FFFFFF/#F5F5F5` 与 `#0E0E0E/#141414` 平面层级；品牌主动作是 `#6366F1`，次级强调是亮色 `#7C3AED`、暗色 `#A78BFA`。
- 普通主要按钮使用 Indigo 单色；Agent/品牌入口使用 `#6366F1 → #7C3AED` 短渐变，渐变不扩散到大面积背景。
- 记忆、技能、安全列表使用 `selection` 整行填充（亮色 `#E9E7FF`、暗色 `#312E81`）；设置、编辑窗口和输入控件保留主题色边框焦点；记忆列表容器和后台任务箭头不叠加焦点边框。
- 后台任务默认收起，首个任务出现时自动展开到四行高度；任务标题、活动图标和箭头保持透明背景。
- 记忆/技能搜索框的放大镜继续由独立透明前缀控件按编辑框高度定位；字号和间距仍由 Hermes Mono 共享令牌控制。
- 原生图谱和 Web 图谱按四级 Indigo/Violet 明度映射用户、项目、参考、反馈类别；连接线保持低对比度，闲置呼吸动效不变。
