# 123mshub v1.11.0 Hermes Mono Clean 实施方案

日期：2026-10-03。基线：v1.10.6。详细令牌、来源路径和视觉边界以同目录的 [Hermes-Mono-Clean-UI规范](Hermes-Mono-Clean-UI规范.md) 与 [123ui5.0 MASTER](../../../design-system/123ui5.0/MASTER.md) 为先行设计记录。

## 实施范围

1. 从本机 Hermes Agent 源码读取 `Mono` 共享暗色色板、桌面明色推导函数、CLI 交互色和 Web/Desktop preset；将 Indigo `#6366F1` / Violet `#7C3AED` 与可复现派生令牌写入 `src/mshub/ui5/tokens.json`、`design_tokens.json` 和 Qt fallback。
2. 保留 123mshub 的 PySide6 页面路由、页面分栏、编辑/导入/批量操作、TaskRunner、仓库协议、QWebChannel 和 Sigma/ForceAtlas2；只替换表面、文字、边框、选择/焦点状态、图标着色和动效时长。
3. 将 Qt 壳、记忆/技能/安全列表、任务面板、搜索图标、提示浮层、Web 前端 token 和本地图谱 CSS/JS 统一到 123ui5.0 Indigo/Violet；使用实色选择背景与焦点边框的分工。
4. 重建本地图谱 Vite 资源，冻结版本面到 v1.11.0，使用 PyInstaller onedir 生成唯一完整包，再进行包内冻结模块/资源校验和真实 Windows 图谱烟测。

## 不改变的契约

仓库路径和配置格式、磁盘记忆/技能文件、服务 API、页面入口、快捷键、任务生命周期、图谱数据结构、离线 `file://`/`qrc://` 资源方式和已有窗口尺寸均不改动。Web 前端也完成 Mono token/build 校验；原生发布包按既有架构只携带 Qt 壳和本地图谱岛。

## 完成门槛

- 规范文档在产品修改前建立；两套色板能由 JSON/fallback 复现。
- 全量 pytest、Web `npm test`、`npm run check`、Web/Vite 构建均通过。
- onedir/ZIP、README、SHA256、bundle-check 齐全；冻结 Python 模块与最终源码一致。
- Windows 最终 EXE `--smoke-float-stable --repo D:\\MSH` 退出码为 0、无 TCP 监听、节点/边有效、`rafActive=true`、`floatTime` 前进、帧哈希不同、`float-alive=True`。
