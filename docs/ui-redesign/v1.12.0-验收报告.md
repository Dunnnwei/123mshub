## 代码检查落实的修复

1. 自动同步将预览、回调和待执行任务绑定到仓库、记忆路径、来源和开关快照；过时结果被丢弃，防止切换目标后误写。设置保存继续阻止在后台写任务执行时切换仓库。
2. 图谱刷新引入 RequestScope；WebEngine profile/cache 使用绝对路径，修复相对配置路径下的渲染器响应延迟；Qt 控制台错误等级使用枚举比较。
3. 任务轮询只在可见状态变化时发信号；清理未保留任务的重试闭包；窗口及图标布局的延时回调绑定 QObject 生命周期。
4. ZIP 升级拒绝路径穿越、Windows ADS/设备名/尾点尾空格别名、大小写重复条目及符号链接；比较大型 DLL 使用 1 MiB 流式块。
5. 界面适配统一中文回落、真实 HAUI 字体、DPR 图标坐标、下拉箭头和类别颜色；主题、调色板、强调色独立持久化。
6. 构建写入 PE 版本信息和完整包说明，产生逐文件发布清单；冒烟有明确超时且必须确认图谱就绪，避免未完成检查却返回成功。
7. 依赖锁文件从早期 skillrepo 元数据对齐到 mshub 1.12.0，补齐 native 依赖；Python/npm 版本清单一致性和 `uv lock --check` 通过，未更换已测试运行环境的依赖。

全量测试有两条来自测试依赖的弃用警告：Starlette 的 httpx TestClient 路径、AnyIO BlockingPortal 别名。没有测试失败。

Defender 引擎 `1.1.26090.9`，病毒库 `1.461.110.0`，更新于 `2026-10-20T00:13:15.0000000+08:00`。标准 onedir、无 UPX、无混淆、无需管理员权限；未关闭防护或添加排除项。EXE 的 Authenticode 状态为 **NotSigned**，文件/产品版本均为 1.12.0。本机结果不保证 SmartScreen 或其他杀毒产品不提示。
