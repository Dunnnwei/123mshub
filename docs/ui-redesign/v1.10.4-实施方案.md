# v1.10.4 列表统一与后台任务交互修复

日期：2026-10-02。基线：v1.10.3。

## 产品与边界

123 MSHub 面向在本地共享记忆、技能与程序的 Agent 用户。高频操作是比较条目、双击编辑、处理后台任务失败；本版以记忆仓库现有列表为视觉参照，修正不同 Qt 控件造成的表现差异。沿用 PySide6 Widgets、本地 QWebEngine/QWebChannel、服务和存储协议，不引入网络渲染服务。

保留 Silk/Mica 主题：亮色表面 #F0F2F8、亮色文字 #2E3040；暗色表面 #131B2E、暗色文字 #DAE2FD；主题色 #6366F1 和 #7C3AED。字体继续使用 Qt 系统字体；名称加粗，说明使用更小的次级文字。列表左对齐，选择仅使用整行浅染。

## 七项实现与验收

| 指令 | 实现 | 核验 |
| --- | --- | --- |
| 1 摘要背景 | 提示框显式使用当前应用主题的表面、文字、边线颜色，文本按纯文本显示 | 亮暗主题截图与颜色值 |
| 2 任务按钮 | 三个按钮共享字号、颜色、字重、手型光标和显示条件；无任务或面板折叠时全部隐藏 | 空/有任务/折叠三态 |
| 3 任务布局和重试 | 标题固定一行，图标与标题靠左，箭头靠右；折叠高度固定且禁拖，展开顶对齐并恢复拖动高度；用任务 ID 保持选择；详情适用所有任务，下载、翻译、保存等任务从提交时快照重试 | 真实鼠标点击、布局几何、失败→重试→成功；不在运行中重复提交 |
| 4 底部提示 | 统一为“ 双击可打开编辑  ·  可使用 Shift 连选 ”（键名使用正确的 Shift） | 三页文案与英文映射 |
| 5 三表统一 | 技能/安全使用圆角表格卡、独立表头、仅表头下方滚动；移除原生逐单元格选中装饰；名称列以双行呈现名称与说明，说明字段保留为隐藏可排序数据；标签、来源、时间、安全等其余字段保留；保持多选、排序、列宽拖动、悬停、双击和键盘操作 | 三页亮暗截图、选中行像素/委托、滚动条起点、圆角、排序、悬停和列宽回归 |
| 6 页头按钮 | 记忆页新建、编辑、Agent 三按钮按同一最大内容尺寸等宽等高，保留原有填充/线框层级 | 三按钮尺寸相等 |
| 7 编辑布局 | 条目身份、目录名、来源地址、解析预览各一行；来源类型/所属库、版本/标签组成两行两列；底部提示在左，自动翻译/保存/关闭三按钮等尺寸并排靠右 | 表单各字段保留、输入保存、按钮几何与截图 |

第 7 条原文重复“解析预览”，用户已确认短项按“来源类型”处理；因此实际布局为四个长字段各占一整行，来源类型/所属库、版本/标签组成两行两列。
