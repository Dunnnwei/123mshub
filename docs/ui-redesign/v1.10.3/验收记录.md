## 本版验收范围

1. 侧栏安全中心数量改为 `security_status != safe` 的待确认数量；技能仓库仍显示完整安装总数。
2. 原生技能库存过滤缺失安装目录；当前行双击校验稳定身份，失败只提示“未能打开该项目”，不回退到其他条目。
3. 添加/编辑技能均支持标签；编辑通过 native 适配层组合既有元数据与标签公开入口。
4. 搜索框启用清除按钮；后台任务提供详情/重试，失败与未完成状态使用红色字体。
5. 技能表列顺序为“多选、名称、标签、说明、来源、时间、安全”；安全中心补齐标签/说明列；闲置列分隔线不绘制竖条纹。
6. 技能、记忆、安全列表悬停使用可换行矩形小圆角摘要；记忆来源按中英文界面映射为“导入 / 存储 / Agent投递”及 `Imported / Stored / Agent delivery`；记忆表头统一左对齐。
