## 审查基准

按照 skill 的“先基于真实产品内容建立设计计划，再对照 brief 复核，最后批评并验证”的流程检查本次改动。123 MSHub 的核心任务是本地 Agent 用户在记忆与技能库中快速找到条目、比较来源/标签/说明/安全状态并继续编辑或检查，因此本版保留靛蓝/紫罗兰身份、原生 Widgets 架构和浅染选中态，把阅读层级集中到可比较的信息列与错误处置。

审查后的 UI 约束为：

- 表头只使用指定靛蓝 `#6366F1`（暗色/亮色共用），不额外引入装饰色；
- 列表保持左起信息流，技能表固定为“多选 → 名称 → 标签 → 说明 → 来源 → 时间 → 安全”；
- 标签和说明悬停使用同一块可换行的矩形小圆角提示，最大宽度 420px；
- 失败操作在任务面板内提供可见的“详情 / 重试”，而不是要求用户寻找单行 tooltip；
- 选中态只保留整行浅染，列分隔线仅在悬停或拖动时显示，避免表格出现竖条纹。

## 已检查的页面与交互

技能仓库检查了列标题、列值映射、标签输入、搜索框清除按钮、悬停摘要、空目录过滤、当前行双击和无效目录提示。安全中心检查了独立的待确认数量、标签/说明悬停、表头主题色和新列排序。记忆仓库检查了来源词汇、左对齐表头/数据列和完整摘要提示。后台任务检查了失败/未完成红色字、详情消息框、安装重试和右对齐动作组。
