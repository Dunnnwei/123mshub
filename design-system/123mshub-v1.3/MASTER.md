# 123mshub v1.3 设计系统

依据：现有 styles.css 中 123UI v4.2 token + 用户要求的 iOS 27 玻璃动效。配套设计搜索脚本缺失，本文件由现有系统与 ui-ux-pro-max 规范人工整理。

## 布局
- 236px 玻璃侧栏，主内容留白 32px；侧栏顶部品牌、中部五项导航、底部皇家蓝注入入口。
- 主标题和短说明形成稳定页头，操作右对齐；工具栏拆为搜索、资产类别、用户标签三层，标签默认一行可展开。
- 内容采用列表，名称最大权重，时间/平台小字次之，来源/安全/安装状态按语义相邻排列。
- 详情占满侧栏右侧的工作区，移动端全屏；表单可读宽度，长内容独立滚动。

## 色彩与材质
- 皇家蓝 #0156FC；浅底 #F7F5F2，浅正文 #000A1E；深底 #030711，深卡 #0C1730，深色小蓝字 #568EFD。
- 按钮统一 12px 圆角、40px 高；控件 10px；玻璃面板 20px。只有一个主操作使用蓝底白字。
- 玻璃保留背景模糊、顶边镜面高光与底边深度；正文不叠多层模糊，保证清晰和性能。
- 红/绿仅表示风险/成功；图关系使用蓝的透明度、虚实线和文本图例区分，不只靠颜色。

## 字体
- 系统字体 -apple-system / Segoe UI / PingFang SC / Microsoft YaHei；正文 14px，列表标题 15px/600，页标题 30px/650。
- 时间、计数用 tabular-nums；正文行高 1.6。不得将重要说明藏成微小装饰字。

## 动效
- hover/按下 120ms，淡入 200ms，抽屉 320ms spring；仅 transform/opacity，保留现有 token。
- 点击抽屉即开，加载中指示不阻断关闭；图示用 GSAP 进入/聚焦，生命周期清理。
- prefers-reduced-motion 关闭位置动画，内容即时可用；图布局稳定后停止耗电循环。
- 工具提示 180ms，键盘 focus 同样显示；不能只靠浏览器原生 title。

## 无障碍与状态
- 焦点环可见，按钮有可访问名称，列表有 checkbox 选择替代拖动；Esc 关闭弹层，关闭后焦点返回触发处。
- 主体小字对比度至少 4.5:1；深浅色分别检查。
- 所有远程行为有 loading/error/retry，批量任务清楚报告成功、跳过、失败。
- 中英文不改变资产正文；长英文自动折行；375px 无横向页面滚动。

## 工程克制与反模式
- 复用现有 Vue、Lucide、任务系统、markdown 和 CSS；不换字体包、不增加 UI 框架、不新增图数据库。
- 不用随机边伪装知识联系，不把无凭据平台和导入日期猜成事实。
- 不用全屏等待挡住正常浏览，不把 native title 当快速提示，不把选择拖动误判成点击。

## 交付检查
- 四个宽度、亮暗主题、中文/English、reduced-motion。
- 详情延迟/错误/快速切换，多选/全选/清空，过滤+批量跳过，迁移字段往返。
- 控制台无未处理错误；打包的真实 EXE 版本与资源一致。
